Прегледай текущия Milestone Plan на проекта и го поправи.

Целта е всеки Milestone да бъде разбит на конкретни, изпълними TODO задачи.

Направи следното:

1. Прочети целия съществуващ Milestone Plan.
2. Провери текущото състояние на проекта и реалния source code, преди да променяш плана.
3. Не приемай, че дадена задача е завършена само защото е описана в документацията.
4. За всеки Milestone:
   - определи точната му цел;
   - разбий го на малки TODO задачи;
   - всяка TODO задача трябва да представлява конкретна промяна в кода, тест, build стъпка или проверка;
   - задачите трябва да могат да се изпълняват последователно една по една.
5. Ако един Milestone е прекалено голям, раздели го на под-Milestones.
6. Добави зависимости между задачите, когато са необходими.
7. Не смесвай няколко независими функционалности в една TODO задача.
8. За всяка задача посочи:
   - ID
   - кратко име
   - какво трябва да се направи
   - кои файлове/директории вероятно ще бъдат засегнати
   - dependencies
   - критерий за завършеност
   - тест/verification
9. Разграничи ясно:
   - DONE — реално имплементирано и проверено
   - IN PROGRESS — започнато, но незавършено
   - TODO — липсва
   - BLOCKED — зависи от друга задача
10. Не изтривай съществуваща информация, ако не е доказано, че е грешна. При конфликт между документацията и source code използвай source code като източник на истината и отбележи конфликта.
11. Не измисляй имплементация, която не съществува.
12. След анализа пренапиши Milestone Plan в практичен формат, подходящ за AI coding agent.

Желаният формат е:

Milestone M1 — <name>

Goal

<ясна цел>

Status

<status>TODO

  - Description:
  - Files:
  - Dependencies:
  - Done when:
  - Verification:

- [ ] M1-T02 — <task>
  
  - Description:
  - Files:
  - Dependencies:
  - Done when:
  - Verification:

Dependencies

- M1-T01 → M1-T02
- M1-T02 → M1-T03

Milestone Completion Criteria

- [ ] ...
- [ ] ...
- [ ] ...

Повтори това за всички Milestones.

Накрая направи отделна секция:

Execution Order

Подреди всички TODO задачи в правилния ред за изпълнение.

Current Reality Check

Покажи:

- какво действително е готово;
- какво липсва;
- какво е само документация;
- кои Milestones са нереалистично големи;
- кои задачи трябва да бъдат разделени допълнително.

ВАЖНО:
Първо анализирай проекта и source code-а.
След това коригирай плана.
Не започвай имплементация.
Първата цел е да получим точен и изпълним Milestone → TODO план.
